# Operational registration amendment v2 — 2026-10-08

Registered before the first live follow-up request. This amendment changes only local execution accounting and failure reporting. The v1 sixteen-file freeze and ready.json are preserved byte-for-byte in prior-v1-prelive/. The 375 historical initial-error cases, 166 SAT cases, selection, prompts, scoring, analysis, protocol, and historical-source hashes remain unchanged. These are reused historical cases, not new independent samples.

1. An unexpected runner exception or interruption records FAILED_LOCAL_ERROR, preserves the exception type, and exits unsuccessfully. It cannot report ALL_SELECTED_CASES_PROCESSED. LocalStop remains STOPPED_PARTIAL with its machine code.
2. Durable raw status=ok records are authoritative for recovering a missing local model_calls.jsonl record. Recovery uses the exact known usage and deterministic response ID, validates the complete existing usage ledger before appending, and appends each missing record once. An append failure stops execution; a later offline reconciliation can repair a missing row or recognize a row already fully written. Conflicting IDs, changed requests, duplicate or orphan usage rows, malformed partial rows, or unequal usage projections stop without rewriting existing evidence. No request is replayed, no charge refunded, and no unknown usage invented. The shared monetary proxy ledger is separate and is not modified by this repair.

Failed, started, unknown, and locally blocked call identities are not automatically retried.
