\section{Experiments}
\subsection{Reasoning results}
We use the first scientific execution of the tenth engineering run as the primary result because it accompanies the first completed public workflow with this frozen reporting implementation. We did not select it by accuracy. Earlier executions reused the same evaluation set during engineering diagnosis; the tenth run is not a fresh, blinded test or ten independent samples. An independent review recomputes answer validity, paired counts, intervals, usage, and parent/child record correspondence from retained replies. All 24 items remain in each denominator; all 52 returned calls have valid structured answers and finish reason \texttt{stop}.

Diagnostic-minus-generic accuracy is $1/24=0.0417$. Both arms are correct on 11 items and incorrect on 12; exactly one item is diagnostic-only correct and none generic-only correct. Thus $b=1,c=0$ and exact two-sided $p=1.0$. A single discordance cannot provide conventional significance under this test. This is inconclusive evidence, not proof of no effect or equivalence. Relative to the shared initial answer, generic repairs one of 14 failures (graph-11), and diagnostic repairs two (graph-07 and graph-11). Both repairs occur on easy graph items; there is no observed repair in arithmetic, SAT, or hard items (Table~\ref{tab:groups}). Of the 14 generic retries, ten reproduce the initial raw text and 11 reproduce its parsed JSON. One shared repair and three text changes that remain incorrect show why text change cannot stand in for reasoning improvement. The initial first-error categories are five arithmetic mismatches, four unsatisfied clauses, three graph cost mismatches, and two nonoptimal paths. The final diagnostic arm retains 12 errors, not all 14 initial errors.

\subsection{Separate artifact-gate pilot}
A specification-derived fault-injection set contains four valid controls and 20 annotated blockers, four assigned to each gate rule. The historical full gate yields 20 true positives, four true negatives, and no false positives/negatives on this set. A defined terminal-trusting policy accepts every injected fault; a PDF-only baseline detects four of 20. Thirty evaluations per fixture yield 720 recorded timed evaluations, with median 11.58445 ms and p95 23.923825 ms. These are repeated timings of 24 fixtures, not 720 independent defects; retained aggregates lack the 720 raw samples and bind an earlier gate, not current-runtime speed. For the 20 ledgers valid enough to aggregate, the before/after unique-call token delta is zero. Leave-one-rule decisions posthoc filter the full audit rather than rerun a reduced gate. APG002/APG003 fixtures have coupled failure behavior, so this cannot establish that APG002 is redundant. This controlled coverage does not establish resistance to arbitrary corruption, scientific correctness, or reasoning gains.
