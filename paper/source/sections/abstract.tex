A research agent can generate a plausible manuscript without leaving a complete, reviewable execution record. We implement an Artifact Provenance Gate inside JiuwenSwarm that checks a PDF, successful terminal Reporting, contained declared artifacts, aggregable model usage, and citation-key resolution when reliable LaTeX evidence exists. A specification-derived pilot rejects 20 injected blocking faults and accepts four valid controls; these fixtures test artifact integrity rather than scientific truth. We separately study whether one deterministic error diagnostic helps a model repair structured reasoning beyond generic reconsideration with the same retry opportunity. On 24 synthetic arithmetic, satisfiability, and shortest-path items, shared initial answers achieve 10/24 accuracy, generic retry 11/24, and diagnostic retry 12/24. The paired difference is one item, with diagnostic-only/generic-only discordance 1/0 and exact two-sided McNemar $p=1.0$. The reasoning pilot is inconclusive. Its 52 actual calls consume 9,500 input and 888 output tokens. We disclose ten engineering executions on the same items, preserve failures, and distinguish the completed Agent manuscript from this independently compiled, operator-amended paper. Neither artifact validation nor repeated engineering runs establish a general reasoning improvement.
